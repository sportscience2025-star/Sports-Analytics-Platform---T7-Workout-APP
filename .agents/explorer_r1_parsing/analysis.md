## 2. Complete Data Object Trace (`result`)

The `result` object passed into `_exportProgramToExcel(result)` is generated by `window.AI.generateFullProgram(params)` in `js/logic.js`. It contains the following properties and nested fields:

### `result.meta` (Program & Athlete Metadata)
- `splitName`: Split classification (e.g., `"Upper / Lower"`, `"Push-Pull-Legs"`, `"Full Body x2"`)
- `riskLevel`: Subject risk classification (`"LOW"`, `"MEDIUM"`, `"HIGH"`)
- `goal`: Program objective (e.g., `"Ipertrofia"`, `"Forza Massima"`, `"Riabilitazione Ginocchio"`)
- `level`: Experience level (`"Principiante"`, `"Intermedio"`, `"Avanzato"`)
- `patientType`: Subject type (`"Atleta"`, `"Clinico"`, `"Clinico_Anziano"`)
- `sportPraticato`: Primary sport (`"Bodybuilding"`, `"Sport di Squadra"`, `"Endurance"`, `"N/A"`)
- `days`: Number of workout days per week (e.g., `2`, `3`, `4`, `5`, `6`)
- `weeks`: Total macrocycle duration in weeks (e.g., `12`, `16`)
- `equipment`: Available equipment (`"Full Gym"`, `"Minimal"`, `"Calisthenics"`)
- `pathologyNames`: Array of clinical condition names (e.g., `["Lesione LCA post-op", "Gonartrosi"]`)

### `result.periodization` (Periodization Strategy)
- `method`: Identifier (`'LINEAR'`, `'BLOCK'`, `'DUP'`, `'CONJUGATE'`, `'CLINICAL'`, `'POLARIZED'`)
- `name`: Full title (e.g., `"Periodizzazione Lineare"`, `"Periodizzazione a Blocchi (Block Periodization)"`)
- `rationale`: Theoretical justification text referencing authors (e.g. Zatsiorsky, Bompa, Issurin, Rhea)
- `progressionPattern`: Macrocycle progression mechanics
- `keyResearchers`: Scientific references

### `result.summaryRationale`
- Comprehensive text explaining the periodization strategy customized for the specific athlete profile.

### `result.progression` (Timeline Progression Table)
Array of block/phase progression rows:
- `phase`: String phase name (e.g., `"Fase 1: Adattamento Neuromuscolare"`)
- `weeks`: Week range (e.g., `"Settimane 1-3"`)
- `vol`: Volume level (`"Alto"`, `"Moderato"`, `"Medio-Basso"`, `"Basso"`)
- `int`: Intensity level (`"60% RM"`, `"67% RM"`, `"75% RM"`, `"85% RM"`, `"Scarico"`)
- `note`: Operational note (e.g., `"Focus su apprendimento motorio e stabilità."`)

### `result.phases` (Array of Phase Objects)
Each phase contains:
- `id`: Phase number (`1`, `2`, `3`, ...)
- `name`: Phase title (e.g., `"Fase 1: Adattamento Neuromuscolare"`)
- `weeks`: Week breakdown (e.g., `"Settimane 1-3"`)
- `objective`: Strategic goal description
- `focus`: Key focuses
- `vol`: Volume description
- `int`: Intensity description
- `splitName`: Phase split
- `isDeload`: Boolean flag for deload phase
- `schedule`: Array of Day Objects:
  - `name`: Day title (e.g., `"Giorno 1: Upper Body - Spinta"`, `"Giorno 2: Lower Body"`, `"🛌 RIPOSO"`)
  - `focus`: Day focus areas
  - `isRest`: Boolean flag (`true` if rest day)
  - `estDuration`: Estimated session duration in minutes
  - `exercises`: Array of Exercise Objects:
    - `name`: Full exercise name (e.g., `"Bench Press / Panca Piana"`)
    - `isWarmup`: Boolean (`true` if warmup exercise)
    - `isCardio`: Boolean (`true` if cooldown/cardio exercise)
    - `isMain`: Boolean (`true` if main lift vs accessory)
    - `isadapted`: Boolean (`true` if modified for clinical safety)
    - `specs`: Object containing execution parameters:
      - `sets`: Number of sets (e.g., `4`)
      - `reps`: Target reps (e.g., `"8-10"`, `"12-15"`, `"5"`)
      - `load`: Target load / intensity (e.g., `"75% RM"`, `"RPE 8"`, `"A corpo libero"`)
      - `rpe`: Target RPE value (e.g., `8`, `7.5`, `6`)
      - `tempo`: Execution tempo string (e.g., `"3-0-1-0"`, `"2-0-2"`)
      - `rest`: Rest duration (e.g., `"90s"`, `"3 min"`)
    - `note`: Specific coaching notes, execution instructions, or clinical warnings

### `result.explanations` (Scientific & RAG Technical Notes)
Array of evidence objects:
- `category`: Section category (e.g., `"Metodologia RAG"`, `"Scienza dello Sport"`)
- `title`: Document title or citation header
- `text`: Detailed technical explanation or scientific excerpt
- `citations`: Array of source reference objects
- `sourceMetadata`: Journal, authors, year, similarity score metadata

## 3. Current SheetJS Implementation & Limitations

The current exporter in `js/ui.js` uses SheetJS (`XLSX.utils.aoa_to_sheet`):

```javascript
// Sheet 1: Info Generali (Plain 2-column table)
const infoData = [
    ['Parametro', 'Valore'],
    ['Livello Atleta', meta.level || ''],
    ['Tipo Soggetto', meta.patientType || ''],
    ['Sport Praticato', meta.sportPraticato || 'N/A'],
    ['Obiettivo', meta.goal || ''],
    ['Durata Programma', (meta.weeks || 12) + ' settimane'],
    ['Giorni/settimana', meta.days || ''],
    ['Attrezzatura', meta.equipment || ''],
    ['Livello di Rischio', meta.riskLevel || 'LOW'],
    ['Patologie/Condizioni', (meta.pathologyNames || []).join(', ') || 'Nessuna']
];

// Sheet 2: Timeline (Plain 5-column table)
const timelineData = [ ['Fase', 'Settimane', 'Volume', 'Intensità', 'Focus'] ];

// Sheet 3+: Phase Sheets
// Headers: 4 metadata rows, then 5 columns: ['Esercizio', 'Serie', 'Ripetizioni', 'Carico', 'Note Coach']
```

### Key Shortcomings of Current Implementation:
1. **Zero Styling**: SheetJS Community Edition generates unstyled cells without custom fonts, background fills, text alignment, or cell borders.
2. **Missing Vital Columns**: In phase sheets, it only exports 5 columns (`Esercizio`, `Serie`, `Ripetizioni`, `Carico`, `Note Coach`). It omits `RPE`, `Tempo`, `Recupero (Rest)`, `Tipo (Main/Accessory/Warmup/Cooldown)`, `Index #`, and `Athlete Tracking Notes`.
3. **No Header Block Formatting**: Phase title and metadata are plain text in rows 1-4 without background banners or merged cells.
4. **Unmerged Day Headers**: `day.name` is placed in column A with empty cells in B-E, making day headings hard to distinguish.
5. **No Visual Row Differentiation**: Warmup and cooldown rows are distinguished only by suffixing `(Riscaldamento)` or `(Defaticamento)` to exercise names, rather than applying distinct row background colors (`#fef3c7` for warmup, `#f0f9ff` for cooldown).
6. **No Column Auto-Fit**: Excel opens sheets with default narrow column widths, truncating exercise names and coaching notes.

## 4. ExcelJS Architecture & Implementation Strategy

### Step 1: Script Tag Insertion (`index.html`)
Add ExcelJS CDN tag to `<head>` or before `js/ui.js` in `index.html`:
```html
<script src="https://cdn.jsdelivr.net/npm/exceljs@4.4.0/dist/exceljs.min.js"></script>
```

### Step 2: ExcelJS Workbook & Global Styles Setup
In `js/ui.js` (`_exportProgramToExcel(result)`):
```javascript
if (typeof ExcelJS === 'undefined') {
    alert('⚠️ Libreria ExcelJS non caricata. Ricarica la pagina.');
    return;
}

const workbook = new ExcelJS.Workbook();
workbook.creator = 'T7 Workout Engine';
workbook.lastModifiedBy = 'T7 Workout Engine';
workbook.created = new Date();

// Color Palette Constants
const COLORS = {
```

### Step 5: Phase Tabs ("Fase 1", "Fase 2", etc.) Formatting
For each phase in `result.phases`:

1. **Phase Header Block (Rows 2-4)**:
   - Row 2 (Merged A2:K2): Phase Name (`phase.name`) — Fill `#0f172a`, Font Bold 14pt White, Centered.
   - Row 3 (Merged A3:E3): `"Settimane: " + phase.weeks` | (Merged F3:K3): `"Focus: " + phase.focus` — Fill `#1e293b`, Font 11pt White.
   - Row 4 (Merged A4:K4): `"Obiettivo Strategico: " + phase.objective` — Fill `#334155`, Font Italic 10pt White.

2. **Day Schedule Blocks**:
   For each day in `phase.schedule`:
   - **Merged Day Header (Columns A to K)**:
     - Work Day: Content `day.name` (e.g. `"Giorno 1: Upper Body - Spinta"`). Fill `#0c4a6e` (Deep Blue), Font Bold 12pt White, Left aligned with padding.
     - Rest Day: Content `"🛌 RIPOSO - Giorno di Recupero Attivo/Rigenerativo"`. Fill `#475569` (Slate), Font Bold 12pt White.
   - If Rest Day: Merged row A-K below header: `"Nessuna sessione di allenamento con sovraccarichi prevista per oggi."` Fill `#f8fafc`, Font Italic `#64748b`.
   - If Work Day:
     - **Table Header Row (Columns A to K)**:
       `['N°', 'Esercizio', 'Tipo', 'Serie', 'Ripetizioni', 'Carico / %RM', 'RPE', 'Tempo', 'Recupero', 'Note Coach / Indicazioni Cliniche', 'Registro / Note Atleta']`
       - Fill `#0284c7` (Sky Blue), Font Bold 10pt White, Alignment Center/Middle, Thin border.
     - **Exercise Rows**:
       - For each exercise `ex` in `day.exercises`:
         - Determine row style:
           - **Warmup (`ex.isWarmup`)**: Fill `#fef3c7` (Light Amber), Font Color `#92400e`. Tipo = `"Riscaldamento"`.
           - **Cooldown (`ex.isCardio`)**: Fill `#f0f9ff` (Light Sky), Font Color `#075985`. Tipo = `"Defaticamento"`.
           - **Main Lift (`ex.isMain`)**: Fill `#ffffff`, Font Bold `#0f172a`. Tipo = `"Principale"`.
           - **Accessory (`else`)**: Fill `#f8fafc`, Font `#334155`. Tipo = `ex.isadapted ? "Adattato" : "Accessorio"`.
         - Populated Values:
           - Col A: Item # (`1, 2, 3...`)
           - Col B: `ex.name`
           - Col C: Type string
           - Col D: `ex.specs?.sets || ''`
           - Col E: `ex.specs?.reps || ''`
           - Col F: `ex.specs?.load || ''`
           - Col G: `ex.specs?.rpe || ''`
           - Col H: `ex.specs?.tempo || ''`
           - Col I: `ex.specs?.rest || ''`
           - Col J: `ex.note || ''`
           - Col K: `''` (Blank for athlete notes)
         - Formatting:
           - Cols A, C, D, E, F, G, H, I: Centered.
           - Cols B, J, K: Left aligned. `wrapText: true` on Col J & K.
           - Thin borders `#cbd5e1` on all cells.

### Step 7: Export & File Download
```javascript
const buffer = await workbook.xlsx.writeBuffer();
const blob = new Blob([buffer], { type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet' });
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
const goalName = (meta.goal || 'Programma').replace(/\s+/g, '_');
const dateStr = new Date().toISOString().slice(0, 10);
a.href = url;
a.download = `Programma_${goalName}_${dateStr}.xlsx`;
document.body.appendChild(a);
a.click();
document.body.removeChild(a);
URL.revokeObjectURL(url);
```
