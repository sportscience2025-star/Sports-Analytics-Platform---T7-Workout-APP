# Regola 05: Esportazione Fogli di Calcolo (Excel `.xlsx`)

## Scopo
Assicurare che ogni file Excel esportato per allenatori e preparatori sia sempre libero, chiaro e modificabile a mano senza blocchi.

## Cosa l'AI NON può fare (Divieti assoluti)
- **Mai bloccare il file:** è vietato inserire password di protezione, bloccare singole celle o limitare la modifica dei fogli di calcolo generati.

## Cosa l'AI DEVE fare (Obblighi operativi)
- **Garantire modificabilità totale:** ogni file `.xlsx` o foglio esportato per il coach deve essere completamente modificabile e organizzato con una formattazione tabellare chiara e ordinata, in modo che possa inserire note, correzioni o carichi a mano libera.
